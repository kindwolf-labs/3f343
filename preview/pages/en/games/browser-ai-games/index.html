This page lists recent 3F343 catalog entries for AI-built games that include a browser demo URL — a link you can open in a tab, without a store client. Each card points to the catalog page, the listed demo, and the source repository when we have it.

“Listed demo” only means that URL is stored in the catalog. It does not mean 3F343 completed a playtest. Dates below are catalog dates through 2026-11-14, not game release dates. Descriptions are the catalog text.
